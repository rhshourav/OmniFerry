Built to feel instant when it works, and to recover quietly when it doesn't.

Nearby devices just appear

Discovery runs over your network. If Wi-Fi blocks it, Bluetooth or a typed IP address still gets you connected.

Uses your whole Wi-Fi link

Each file travels over several encrypted connections at once, so one slow lane never holds the rest back.

Picks up where it stopped

Lost signal or restarted app? The transfer continues from the exact chunk.

One send, many devices

Three steps. No setup screen.

Open the app on both devices and you're ready.

1

Open OmniFerry

Both devices on the same Wi-Fi. Allow Private networks when Windows Firewall asks.

2

Choose a device

Drop files or a folder on its card, or click Send. Select several cards to send to all.

3

Approve and receive

The receiver approves once. Choose Always trust for your own devices. Files land in Downloads\OmniFerry.

Honest about what it protects.

TLS protects everything on the wire, devices are verified by certificate fingerprint, and file names can never write outside your download folder. Anyone on your Wi-Fi can see a running device's name, so choose a neutral name on shared networks. Read the full security notes.

Quick answers

A device doesn't show up

Check both are on the same Wi-Fi. Guest networks and AP isolation block discovery. Use Connect by IP on the Devices page, or turn on Bluetooth discovery in Settings.

It can't connect after installing

Allow OmniFerry on Private networks in Windows Security, under Firewall, then Allow an app.

Transfers feel slow

Wi-Fi is the limit. Try the 5 GHz band, or raise Parallel connections in Settings.

Ready when you are.

Run the installer (no administrator needed). Prefer no installer? Each release also has a portable zip. Check the download against SHA256SUMS.txt if you like.
