Built to feel instant

Every detail is tuned for speed, reliability and calm.

Zero setup

Devices on the same Wi-Fi find each other automatically. Bluetooth and manual address are there if your router blocks discovery.

Saturates your Wi-Fi

Each file moves over several parallel encrypted connections, split into checked chunks.

Never loses its place

Pause, resume, auto-retry. A dropped connection or a restarted app continues from the exact chunk.

One to many

Select several devices and send to all at once. Whole folders keep their structure.

Clipboard sync

Private by design

There is no server. Your data goes directly between your devices, encrypted with TLS. Devices are pinned by certificate fingerprint, unknown devices must be approved, and received file names are sanitised. Read the security notes, including the honest limitations.

Questions

A device doesn't show up

Check both are on the same Wi-Fi. Guest networks and "AP isolation" block discovery. Use Connect by IP on the Devices page, or turn on Bluetooth discovery.

Windows Firewall asked something

Allow OmniFerry on Private networks, otherwise other devices cannot reach your PC.

Does it use the internet?

No. Transfers stay on your local network.

Is it free?

Yes, free to use. The source code is not published; the protocol is documented so compatible apps can be built.
