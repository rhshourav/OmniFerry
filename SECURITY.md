# Security policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please **do not open a public issue**. Use **Security -> Report a vulnerability** on this repository to send a private
report. Include the version, what you observed, and steps to reproduce. You will get an acknowledgement within a few days,
and we will credit you in the changelog if you wish.

## Scope
In scope: authentication/handshake flaws, path traversal, memory or disk exhaustion by a remote peer, clipboard or
web-gateway access without authorisation, and anything that exposes data to devices that were not approved.
The documented [known limitations](docs/security.md#known-limitations-be-honest-with-users) are not vulnerabilities.
